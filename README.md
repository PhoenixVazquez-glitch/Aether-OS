# Aether-OS
Aether OS + Alejandro AI is a sleek offline-first Flutter app blending cyberpunk aesthetics with powerful privacy tools. Broadcast local sales via Bluetooth mesh (Bridgefy), store data persistently with Isar, and manage state smoothly with Riverpod. Speak “System Freeze 7.3” to instantly purge all data and exit — a true self-destruct kill switch.
